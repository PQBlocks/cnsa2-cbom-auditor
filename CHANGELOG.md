# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-11-23

### Added
- Initial public stable release of `@pqblocks/cnsa2-cbom-auditor`.
- CycloneDX 1.6 Cryptographic Bill of Materials (CBOM) generation.
- NSA CNSA 2.0 and NIST PQC migration timeline classification engine.
- X.509, SPKI, PKCS#8, and JWK credential format scanning.
- CBOM schema validation with AJV.
- Delta comparison engine between baseline and target audits.
- CLI commands: `scan`, `verify`, `compare`.
